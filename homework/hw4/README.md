# 通用迭代法抽象框架與九大經典演算法實作說明

本專案透過軟體工程中的**高階函數（Higher-Order Function）**與**控制反轉（Inversion of Control）**設計模式，將數值分析、線性代數、微分方程與機器學習中常見的九種經典演算法，統一抽象化為單一的「狀態轉移與收斂判定」迭代模型。

---

## 一、 核心通用迭代框架 (`generic_iterator`)

### 1. 設計理念
幾乎所有的數值迭代演算法在數學本質上皆可表示為離散動力系統的狀態推進：
$$s_{k+1} = T(s_k)$$
無論演算法內部是在求方程式的根、解線性系統、尋找矩陣特徵值，或是進行機器學習分群，其演算法骨架皆完全相同，唯一的差異僅在於：
1. **狀態（State）的資料結構**：可能是純量（Scalar）、向量（Vector）、矩陣（Matrix）或複合元組（Tuple）。
2. **狀態推進規則（Transition Function）**：如何從當前狀態 $s_k$ 計算出下一狀態 $s_{k+1}$。
3. **終止條件（Convergence Criterion）**：如何判定狀態已穩定收斂或達到目標終點。

### 2. 介面規格
```python
def generic_iterator(transition_func, is_converged, initial_state, max_iter=1000)
```
* **`transition_func(state)`**：接收當前狀態 $s_k$，回傳推進後的下一狀態 $s_{k+1}$。
* **`is_converged(state, next_state, iteration)`**：接收前後狀態與當前步數，回傳布林值（`True` 代表已收斂並終止迴圈）。
* **`initial_state`**：迭代起點 $s_0$。
* **`max_iter`**：安全防護上限，避免發散問題導致無窮迴圈。

## 二、 九大經典迭代演算法原理解析與對照表

| 編號 | 演算法名稱 | 應用領域 | 狀態 $s_k$ 型態 | 狀態推進函數 $T(s_k)$ 核心邏輯 | 收斂/終止判定條件 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | **二維不動點迭代** | 非線性系統求解 | 1D 向量 `(2,)` | 代入線性/非線性映射 $X_{k+1} = G(X_k)$ | 歐氏距離 $\|X_{k+1} - X_k\|_2 < 10^{-6}$ |
| **2** | **牛頓法 (Newton)** | 非線性方程式求根 | 浮點數 `float` | 切線逼近 $x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}$ | 絕對誤差 $|x_{k+1} - x_k| < 10^{-6}$ |
| **3** | **高斯-賽得爾法** | 大型聯立線性方程組 | 1D 向量 `(n,)` | 逐分量即時更新 $x_i^{(k+1)} = \frac{1}{a_{ii}}(b_i - \sum_{j \neq i} a_{ij}x_j)$ | 最大分量誤差 $\|x_{k+1} - x_k\|_\infty < 10^{-6}$ |
| **4** | **冪次迭代法** | 主特徵值與特徵向量 | 1D 單位向量 `(n,)` | 矩陣乘法並正規化 $v_{k+1} = \frac{Av_k}{\|Av_k\|_2}$ | 向量逐元素逼近 `np.allclose` |
| **5** | **QR 演算法** | 矩陣全特徵值計算 | 2D 矩陣 `(n, n)` | 正交分解並反序相乘 $A_k = Q_k R_k \Rightarrow A_{k+1} = R_k Q_k$ | 非對角線元素絕對值總和 $< 10^{-6}$ |
| **6** | **龍格-庫塔法 (RK4)** | 常微分方程初值問題 | 元組 `(t, y)` | 四階加權斜率推進 $y_{k+1} = y_k + \frac{h}{6}(k_1+2k_2+2k_3+k_4)$ | 獨立變數抵達終點 $t \ge t_{\text{end}}$ |
| **7** | **PageRank** | 圖論網路節點排名 | 1D 機率向量 `(n,)` | 馬可夫鏈轉移 $r_{k+1} = G r_k$ | 歐氏距離 $\|r_{k+1} - r_k\|_2 < 10^{-6}$ |
| **8** | **K-Means 聚類** | 非監督式資料分群 | 2D 座標矩陣 `(k, d)` | E步分配最近群心 $\rightarrow$ M步重算群心均值 | 群心最大移動量 $\|C_{k+1} - C_k\|_\infty < 10^{-6}$ |
| **9** | **EM 演算法** | 含隱變數之機率估計 | 參數元組 $(\theta_A, \theta_B)$ | E步計算隱變數期望權重 $\rightarrow$ M步最大化概似估計 | 雙參數絕對變化量皆 $< 10^{-6}$ |

## 三、 各演算法模組詳細說明

### 1. 二維不動點迭代法 (`demo_fixed_point`)
* **數學原理**：求解 $X = G(X)$。根據巴拿赫不動點定理（Banach Fixed-Point Theorem），當映射 $G$ 為壓縮映射（Contraction Mapping，即雅可比矩陣的譜半徑 $\rho(J) < 1$）時，不論初始點為何，序列必唯一收斂至不動點。
* **程式實作細節**：定義二維仿射轉換，利用 `np.linalg.norm(new - old)` 計算前後兩次狀態向量的二範數（Euclidean Norm）作為收斂依據。

### 2. 牛頓法求根 (`demo_newton`)
* **數學原理**：將非線性函數 $f(x)$ 在當前猜測點 $x_k$ 進行一階泰勒展開，取切線與 $x$ 軸的交點作為下一近似值：$x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}$。
* **程式實作細節**：求解 $x^2 - 4 = 0$（正根為 $2$）。牛頓法具備**二次收斂（Quadratic Convergence）**特性，僅需 5 次迭代即達到 $10^{-6}$ 精度。

### 3. 高斯-賽得爾法 (`demo_gauss_seidel`)
* **數學原理**：用於求解線性系統 $Ax = b$。與雅可比法（Jacobi Method）不同的是，高斯-賽得爾法在計算第 $i$ 個分量 $x_i^{(k+1)}$ 時，會**立即使用同一次迭代中已經更新完畢的前序分量** $x_0^{(k+1)}, \dots, x_{i-1}^{(k+1)}$，從而加快收斂速度並節省記憶體。
* **程式實作細節**：矩陣 $A$ 為嚴格對角占優矩陣（Strictly Diagonally Dominant），保證演算法必然收斂。收斂條件採用無窮範數（Infinity Norm）`np.max(np.abs(new - old))`。

### 4. 冪次迭代法 (`demo_power_iteration`)
* **數學原理**：將任意初始非零向量反覆乘上矩陣 $A$，向量方向會逐漸對齊絕對值最大的特徵值（主特徵值 $\lambda_1$）所對應的特徵向量。為避免數值溢位（Overflow）或下溢（Underflow），每步皆除以自身範數進行正規化。
* **程式實作細節**：收斂後獲得單位主特徵向量 $v$，最後透過**瑞利商（Rayleigh Quotient）** $\lambda = v^T A v$ 算出最大特徵值。

### 5. QR 演算法 (`demo_qr_algorithm`)
* **數學原理**：計算矩陣「所有特徵值」的黃金標準演算法。在每一步將矩陣分解為正交矩陣 $Q_k$ 與上三角矩陣 $R_k$（即 $A_k = Q_k R_k$），接著反向相乘定義 $A_{k+1} = R_k Q_k$。因為 $A_{k+1} = Q_k^T A_k Q_k$ 為相似變換（Similarity Transformation），特徵值保持不變，且矩陣會逐漸收斂為上三角（或對角）矩陣。
* **程式實作細節**：巧妙利用 Python 解包語法 `np.dot(*reversed(np.linalg.qr(Ak)))` 一行完成分解與反序相乘；當非對角線元素總和趨近於 0 時，對角線元素即為全體特徵值。

### 6. 四階龍格-庫塔法 (`demo_rk4`)
* **數學原理**：求解常微分方程初值問題 $\frac{dy}{dt} = f(t, y), y(t_0) = y_0$。在每個步長 $h$ 區間內，分別取起點斜率 $k_1$、兩個中點預估斜率 $k_2, k_3$ 與終點預估斜率 $k_4$，以 $\frac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)$ 的辛普森積分權重推進，局部截斷誤差達 $O(h^5)$。
* **程式實作細節**：此處展示了通用框架的高度彈性——這裡的迭代並非為了「逼近某個不動點」，而是「沿著時間軸推進直到目標時間 $t_{\text{end}}$」。因此 `is_converged` 判定的是時間變數 `new[0] >= t_end`。

### 7. PageRank 演算法 (`demo_pagerank`)
* **數學原理**：將全球資訊網視為有向圖，網頁權重即為馬可夫鏈的平穩分佈（Stationary Distribution）。為解決死胡同（Dead Ends）與蜘蛛陷阱（Spider Traps），引入阻尼係數（Damping Factor）$d = 0.85$，構造 Google 轉移矩陣：
  $$G = dM + \frac{1-d}{n}\mathbf{1}\mathbf{1}^T$$
* **程式實作細節**：本質上是針對隨機矩陣 $G$ 進行主特徵值為 $1$ 的冪次迭代，因為機率向量總和恆為 $1$，推進函數僅需單純執行矩陣乘法 `np.dot(G, r)`。

### 8. K-Means 聚類演算法 (`demo_kmeans`)
* **數學原理**：將資料劃分為 $k$ 個群集以最小化群內平方誤差和（WCSS）。屬於**硬性分配的期望最大化演算法（Hard EM）**：
  * **E-step（期望步）**：固定群心，將每個樣本指派給歐氏距離最近的群心。
  * **M-step（最大化步）**：固定樣本標籤，將每個群心更新為該群所有樣本的幾何中心（算術平均數）。
* **程式實作細節**：利用 NumPy 廣播機制（Broadcasting）`X[:, np.newaxis] - centroids` 免除迴圈快速計算距離矩陣，當群心不再移動時即告收斂。

### 9. EM 演算法：雙硬幣問題 (`demo_em_two_coin`)
* **數學原理**：經典的統計潛在變數（Latent Variable）參數估計問題。假設有兩枚出現正面機率未知的硬幣 $A, B$（參數 $\theta_A, \theta_B$），每次實驗隨機抽出一枚投擲 10 次並記錄正反面次數，但**未記錄抽中哪一枚硬幣**。
  * **E-step**：根據當前參數估計值 $(\theta_A^{(k)}, \theta_B^{(k)})$，利用貝氏定理計算每一輪實驗是由硬幣 $A$ 或 $B$ 產生的後驗機率權重 $(p_A, p_B)$，並計算期望正反面次數。
  * **M-step**：將加權後的期望正面次數除以期望總投擲次數，得出更新後的參數 $(\theta_A^{(k+1)}, \theta_B^{(k+1)})$。
* **程式實作細節**：完整重現了文獻（Do & Batzoglou, *Nature Biotechnology*, 2008）中的經典範例，展示 EM 演算法如何在缺乏標籤資訊下保證對數概似函數（Log-Likelihood）單調遞增並收斂至局部最佳解。
