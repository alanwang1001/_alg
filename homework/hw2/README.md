# 演算法遞迴複雜度分析

本筆記針對四個常見的遞迴方程式進行展開求解，推導出精確閉合解（Exact Solution）並分析其對應的時間複雜度（Big O）。

---

## 快速總覽

| 遞迴方程式 | 精確解 T(n) | Big O | 演算法特性說明 |
| :--- | :--- | :--- | :--- |
| T(n) = T(n-1) + 8 | 8n - 7 | O(n) | 線性成長，典型單層循序處理 |
| T(n) = 2T(n-1) + 9 | 5 × 2^n - 9 | O(2^n) | 指數級暴增，樹狀重複展開 |
| T(n) = 2T(n/2) + 1 | 2n - 1 | O(n) | 分治後規模減半但分支加倍，等同遍歷全部節點 |
| T(n) = T(n/2) + 1 | log₂n + 1 | O(log n) | 對數成長，典型二分切割縮減規模 |

---

## 詳細推導過程

### 第 1 題：T(n) = T(n-1) + 8，初始條件 T(1) = 1

每次問題規模減 1，處理需耗費 8 單位時間。

- T(n) = T(n-1) + 8
- T(n) = [T(n-2) + 8] + 8 = T(n-2) + 2 × 8
- T(n) = T(n-3) + 3 × 8
- ...
- 規律：T(n) = T(n-k) + 8k

當展開到終止條件 T(1) 時，令 n - k = 1，可得 k = n - 1：
T(n) = T(1) + 8(n - 1)
T(n) = 1 + 8n - 8
T(n) = 8n - 7

- 精確解：T(n) = 8n - 7
- Big O：O(n)
- 常見場景：單層迴圈、走訪單向鏈結串列。

---

### 第 2 題：T(n) = 2T(n-1) + 9，初始條件 T(1) = 1

每次問題規模減 1，但會分裂成 2 個子任務，另加 9 單位時間。

- T(n) = 2T(n-1) + 9
- T(n) = 2[2T(n-2) + 9] + 9 = 2^2 × T(n-2) + 2 × 9 + 9
- T(n) = 2^3 × T(n-3) + (2^2 + 2 + 1) × 9
- ...
- 規律：T(n) = 2^k × T(n-k) + 9 × (2^0 + 2^1 + ... + 2^(k-1))

當 n - k = 1（即 k = n - 1）：
等比級數總和 2^0 + 2^1 + ... + 2^(n-2) = 2^(n-1) - 1

代入計算：
T(n) = 2^(n-1) × T(1) + 9 × (2^(n-1) - 1)
T(n) = 2^(n-1) × 1 + 9 × 2^(n-1) - 9
T(n) = 10 × 2^(n-1) - 9
T(n) = 5 × 2^n - 9

- 精確解：T(n) = 5 × 2^n - 9
- Big O：O(2^n)
- 常見場景：河內塔問題（Tower of Hanoi）、未做快取的費氏數列暴力遞迴。

---

### 第 3 題：T(n) = 2T(n/2) + 1，初始條件 T(1) = 1

每次把資料切半，但兩半都要各自處理，外加 1 次合併或常數運算。
（假設 n 為 2 的冪次方，即 n = 2^k，k = log₂n）

- T(n) = 2T(n/2) + 1
- T(n) = 2[2T(n/4) + 1] + 1 = 2^2 × T(n/4) + 2 + 1
- T(n) = 2^3 × T(n/8) + 2^2 + 2 + 1
- ...
- 規律：T(n) = 2^k × T(n / 2^k) + (2^0 + 2^1 + ... + 2^(k-1))

當 n / 2^k = 1，此時 2^k = n 且 k = log₂n：
等比級數總和為 2^k - 1 = n - 1

代入計算：
T(n) = n × T(1) + (n - 1)
T(n) = n × 1 + n - 1
T(n) = 2n - 1

- 精確解：T(n) = 2n - 1
- Big O：O(n)
- 常見場景：遍歷滿二元樹所有節點、建立線段樹（Segment Tree）。

---

### 第 4 題：T(n) = T(n/2) + 1，初始條件 T(1) = 1

每次把資料切半，只挑其中一半繼續做，外加 1 次比較運算。
（假設 n 為 2 的冪次方，即 n = 2^k，k = log₂n）

- T(n) = T(n/2) + 1
- T(n) = [T(n/4) + 1] + 1 = T(n/4) + 2
- T(n) = T(n/8) + 3
- ...
- 規律：T(n) = T(n / 2^k) + k

當 n / 2^k = 1，此時 k = log₂n：
T(n) = T(1) + log₂n
T(n) = 1 + log₂n

- 精確解：T(n) = log₂n + 1
- Big O：O(log n)
- 常見場景：二分搜尋法（Binary Search）、快速冪演算法。
